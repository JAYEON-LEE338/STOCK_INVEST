# 투자 전략 (STRATEGY)

한국투자증권 Open API(KIS Developers) 기반 주식 자동매매 프로그램의 투자 전략 정의서.

## 1. 자산 배분
| 구분 | 비중 | 목적 | 매매 대상 |
|---|---|---|---|
| 단타/스윙 계좌 | 총평가금액의 **40%** | 박스권 + 모멘텀 단타 | 코스피/코스닥 반도체, 반도체 소부장, 2차전지, 로봇, AI 전력, 신재생 에너지 |
| 초단타 계좌 | 총평가금액의 **20%** | 급등 초단타 (2.3) | 코스피/코스닥 동일 유니버스 |
| 공포지수 계좌 | 총평가금액의 **40%** | 공포 구간 분할 매수, 안정 구간 분할 매도 | KODEX 200 커버드콜 액티브(`0219E0`) |

- 비중 기준은 매매 시점의 계좌 총평가금액(예수금 + 평가금액)이다.
- 위 비중은 **기본값**이다. 대시보드(대시보드 탭 → 전략 ON / OFF · 투자 비중)에서 **전략별(공포지수·박스권·모멘텀·초단타) 비중을 직접 바꿀 수 있다.**
  - 합계는 100% 를 넘을 수 없고, 100% 미만이면 남은 금액은 현금으로 둔다.
  - 저장 즉시 다음 매수 판단부터 새 비중으로 예산이 계산된다. 이미 보유한 종목은 팔지 않으며, 비중을 낮추면 그 전략은 신규 매수만 멈춘다.
  - 값은 상태 파일에 저장되어 재시작해도 유지되고(모의/실전 별도), "기본값으로"를 누르면 아래 기본 비중으로 돌아간다.
- 기본값에서 단타 예산(40%)은 박스권 전략과 모멘텀 전략이 **50:50**(각각 총평가금액의 20%)으로 나눠 쓴다 (`DAY_SPLIT_BOX`, `DAY_SPLIT_MOM`).
- 두 계좌(버킷)는 논리적으로만 분리하며, 각각 자기 예산을 넘겨 매수하지 않는다.

## 2. 단타 전략 (박스권·모멘텀 40% + 초단타 20%)

### 2.0 공통: 대상 종목군과 주도 섹터
- 유니버스는 `config.py`의 `UNIVERSE`(반도체, 반도체소부장, 2차전지, 로봇, AI전력, 신재생에너지; 코스피·코스닥 혼합)에서 관리한다.
- **주도 섹터**: 섹터별 유니버스 종목의 당일 등락률 평균이 가장 높은 섹터.
- 과열(등락률 20% 이상) 종목은 제외한다.
- **대상 종목 필터** (박스권·모멘텀·초단타 공통): **시가총액 5,000억원 이상** (`MIN_MARKET_CAP`, 시세 API의 HTS 시가총액). (이동평균 정배열 조건은 폐지)

### 2.1 박스권 전략 (코스피 지수 기준)
**박스권 산정**
- 최근 20거래일(오늘 제외) 코스피 일봉으로 계산한다. 데이터는 yfinance `^KS11`.
- 상단 = 고가의 95백분위, 하단 = 저가의 5백분위.
- 박스 폭 `(상단-하단)/하단` 이 5% 미만이면 박스가 아니라고 보고 전략을 쉰다.
- 박스 내 위치 = `(현재지수-하단)/(상단-하단)` (0%=하단, 100%=상단). **UI에 상단/하단/현재 위치를 표시**한다.

**매수**
- 박스 내 위치가 **20% 이하**(하단 근접)이면 **15:20 종가 단일가**에 매수 (아래 "매수 주문 방식").
- 하단을 -10% 넘게 이탈한 경우(박스 붕괴)는 매수하지 않는다.
- 대상: 주도 섹터 안에서 거래대금 상위 2종목 (상승/추세 조건은 요구하지 않음).
- 이미 보유 중이면 박스 예산 한도 내에서만 추가 매수한다.

**매도**
- 박스 내 위치가 **70% / 80% / 90% / 100%** 에 처음 도달할 때마다 보유량(기준 수량)의 **25%씩** 매도 (15:00, 시장가).
- 마지막 단계에서는 잔량 전량 매도.

**손절**
- 수익률(평균 매수가 대비, 왕복 수수료·세금 차감)이 **-5% 이하**(`BOX_STOP_PCT`)가 되면 **전량** 시장가 매도한다.
- 장중 09:05~15:19 1분 간격으로 감시한다. 평균 매수가는 체결 기록을 쓰고, 기록이 없으면 계좌의 매입 평균가를 쓴다.

### 2.2 모멘텀 전략 (10시 기준)
**매수 (10:01)** — 아래를 모두 만족해야 한다.
1. 코스피 지수가 전일 대비 **+1.0% 이상**
2. 종목이 **당일 주도 섹터** 소속이고 상승 중(등락률 > 0)
3. **지수 추세 조건**: 최근 30분(`MOM_TREND_MIN`) 동안 코스피 지수가 **-0.2%(`MOM_TREND_PCT`) 이하로 내려가는 추세면 매수 대상에서 제외**한다. (추세는 KIS 업종 분봉 API로 현재값과 30분 전 값을 비교. 조회 실패·데이터 부족이면 판단 보류 = 이 조건은 통과)
- (거래량 조건은 폐지했다.)
- 조건을 만족한 종목 중 **거래대금 상위 2종목**을 매수.

**오후 재매수 (14:00~14:50, 10분 간격)**
- 위 1~2의 조건을 다시 확인하되, 3번 대신 **지수가 상승 추세(최근 30분 +0.2% 이상)** 일 때만 매수한다. 코스피 +1% 조건(`MOM_PM_INDEX_MIN`)과 주도 섹터/거래대금 선정은 그대로다.
- 하루 1회만 매수한다. 오전에 이미 산 종목도 제외하지 않으며(같은 종목이면 추가 매수, 평균 매수가 갱신), 남은 모멘텀 예산 범위에서 매수한다.
- 오후에 산 종목도 15:19까지 같은 손절/익절 규칙을 적용하고 잔량은 19:30 NXT 에서 매도한다.

**손절/익절 (장중 1분 간격 감시, 10:02~15:19, 시장가)**
- 수익률 = 현재가 / 매수가 - 1 - 왕복 수수료·세금(`MOM_ROUNDTRIP_COST`, 기본 0.25%). 비율은 모두 **최초 매수 수량 기준**이며 각 단계는 1회만 실행한다.
| 조건 | 매도 |
|---|---|
| 수익률 **-3% 이하** | 50% 매도 (손절 1차) |
| 1차 손절 **5분 뒤에도 -3% 이하** | 나머지 50% 매도 (손절 2차, 전량 청산). 5분 뒤 처음 확인한 시점에 한 번만 판단하며, -3% 위로 회복했으면 2차 손절은 하지 않는다 |
| 매수 후 **-2% 이하(`BE_ARM_PCT`)까지 내려갔다가 본전(수수료 포함 0%) 회복** | 30% 매도 |
| 수익률 **+3% 이상** | 30% 매도 |
| 수익률 **+6% 이상** | 30% 추가 매도 |
- 남은 수량은 아래 NXT 매도로 정리한다.

**매도 (잔량)**
- **당일 19:30 넥스트레이드(NXT) 애프터마켓**에서 지정가(현재가 -2틱) 매도.
- 보완: NXT 매도 실패/미체결 시 다음 영업일 **09:05** 정규장에서 시장가 정리.
- **NXT 매도가 실패하면 텔레그램으로 알린다.** (09:05 정리 실패 시에도 알림)

### 2.3 초단타 전략 (총평가금액의 20%)
**예산**: 총평가금액의 **20%** (`SCALP_RATIO`). 모멘텀/박스권 예산과 별도다.

**후보 선정 (09:05 / 09:30 / 10:00 스캔)**
- 유니버스 종목 중 **전일 대비 +5% 이상 상승**(`SCALP_MIN_CHANGE`)하고 **거래량이 전일 거래량의 50% 이상**(`SCALP_VOL_RATE`, 시세 API의 전일 대비 거래량 비율)인 종목. 과열(20% 이상)은 제외.
- 스캔 때마다 후보로 기록하고, 10:00 스캔 가격을 추세 판단 기준으로 쓴다.

**매수 (10:10, 10:20, 10:30 - 종목당 하루 1회, 상위 2종목)**
- 위 후보가 모멘텀 매수 조건(코스피 +1% 이상, 주도 섹터 소속, 지수 하락 추세 아님)을 모두 충족해야 한다.
- **추세가 살아있을 것**: 현재가가 10:00 스캔 가격 이상이고, 등락률이 여전히 +5% 이상.
- **하루 매수는 최대 2종목** (`SCALP_MAX_BUYS`). 손절로 끝난 종목도 횟수에 포함하며, 한도에 도달하면 이후 스캔 시각에는 매수하지 않는다.
- 순위는 거래량 비율(전일 대비) 순. 오늘 **익절한 종목은 다시 매수하지 않는다**.

**매도 (장중 1분 간격 감시, 시장가, 비율은 최초 수량 기준)**
| 조건 | 매도 |
|---|---|
| 수익률 **-3% 이하** | **전량** 매도 |
| 매수 후 **-2% 이하(`BE_ARM_PCT`)까지 내려갔다가 본전(수수료 포함 0%) 회복** | 50% 매도 |
| 수익률 **+3% / +6% / +9% 이상** | 각 단계마다 30% 매도 (익절) |
- 수익률 계산은 모멘텀과 같다 (왕복 수수료·세금 차감).
- 본전 매도는 지정가 주문을 미리 걸어두지 않고, 1분마다 가격을 확인해 본전 회복 시 시장가로 낸다.
- **매수 후 30분 이상 손실 상태이면 텔레그램으로 알린다** (종목당 1회).
- 익절(+3% 이상 매도)이 한 번이라도 나간 종목은 그날 재매수하지 않는다.
- 15:15에 남은 수량을 전량 시장가 정리한다 (오버나이트 없음).

## 3. 공포지수 전략 (40%)

### 3.1 지표
- **VIX 지수**(yfinance `^VIX`)만 사용한다.
- CNN 공포탐욕지수는 자동 조회가 차단(418)되어 현재 사용하지 않는다. (추후 안정적인 소스를 찾으면 병행)

### 3.2 매수 조건
- **VIX 28 이상**이면 매수 신호.
- 대상: **KODEX 200 커버드콜 액티브** (`0219E0`)
- 방식: 신호가 켜진 날 하루 1회, 공포 계좌 예산의 **25%** 씩 분할 매수한다.
  신호가 계속되면 다음 영업일에 이어서 매수하며, 계좌 예산 한도를 넘지 않는다.

### 3.3 매도 조건 (분할 매도)
- VIX가 **15 이하** 로 내려오면 매도를 시작한다.
- VIX가 아래 단계 이하로 처음 내려갈 때마다 **최대 보유 수량의 10%** 씩 매도한다.
  - 단계: VIX 15, 14.5, 14, 13.5, 13, 12.5, 12, 11.5, 11, 10.5 (총 10단계 = 100%)
  - 단계 값은 `config.py`의 `VIX_SELL_LADDER`에서 조정한다.
- 하루에 한 단계만 매도한다.
- 매도 진행 중 다시 매수 신호가 켜지면 매도 단계를 초기화하고 새 사이클로 시작한다.

### 3.4 실행 시점
- 하루 1회 **15:10**, 매수는 지정가(매수 2호가), 매도는 시장가 주문.

## 4. 리스크 관리 (공통)
- **매수 주문 방식 (모든 매수 공통)**: 시장가로 사지 않고, 주문 시점의 **매수 호가 중 두 번째로 높은 가격(매수 2호가)** 에 지정가로 건다. 호가 조회에 실패하면 매수하지 않는다. 지정가라 체결되지 않을 수 있다.
- **체결 추적 (실주문 모드)**: 매수는 주문 접수 시점이 아니라 **체결된 수량·평균가**로 전략 보유를 기록한다. 1분마다 당일 주문체결을 조회해 반영한다. 전략별 보유 수량은 각자 체결분만 세므로, 같은 종목을 여러 전략이 보유해도 다른 전략의 주식을 팔지 않는다.
- **미체결 취소**: 모멘텀·초단타 매수는 주문 후 **10분(`BUY_CANCEL_MIN`)** 안에 다 체결되지 않으면 남은 수량을 취소한다. 하나도 체결되지 않은 종목은 보유 기록을 지운다(초단타 하루 한도에서도 빠진다). 박스권(종가 단일가)·공포지수 매수는 취소하지 않고 장 마감 후 체결분만 반영한다.
- 미체결 매수 금액은 각 전략 예산 사용액에 포함한다.
- **매도 체결 확인**: 매도 주문도 체결을 추적한다. 정규장 매도가 3분(`SELL_ALERT_MIN`) 넘게 미체결이면, NXT 매도는 20:05 기준 미체결이면 텔레그램으로 알린다. 모멘텀 NXT 미체결 수량만 다음 날 09:05에 정리한다.
- **일일 매수 금액 한도**(`MAX_DAILY_AMOUNT`) 사용액은 상태 파일에 저장해 재시작해도 유지된다. (매도는 기존대로 시장가/NXT 지정가)
- **전략별 ON/OFF**: 공포지수·박스권·모멘텀·초단타 각각 대시보드에서 켜고 끌 수 있다(상태 파일에 저장, 재시작해도 유지, 기본 모두 ON). **OFF 는 신규 매수만 막는다.** 이미 보유한 종목의 손절/익절/분할 매도/정리와 체결 추적은 계속 동작한다. 초단타는 OFF 일 때 후보 스캔도 하지 않는다.
- **DRY_RUN 기본 켜짐**: 주문을 보내지 않고 로그만 남기는 모드로 시작한다.
- **모의투자 우선**: 모의투자에서 충분히 검증한 후 실전 전환한다.
- 1회 매수 금액 상한, 일일 총 매수 금액 상한을 코드에서 강제한다 (`MAX_ORDER_AMOUNT`, `MAX_DAILY_AMOUNT`).
- 휴장일/주말에는 동작하지 않는다.
- API 오류, 토큰 만료, 미체결 발생 시 로그를 남기고 재시도 또는 중단한다.
- App Key/Secret/계좌번호는 `.env`에만 보관하고 Git에 올리지 않는다.
- 박스권 전략은 -5% 손절(2.1)만 있고 기간 손절은 없다.

## 6. 확인이 필요한 사항
- [x] 종목코드 0219E0 확인, NXT 시세 조회(`NX`) 확인 완료
- [x] 1분봉 API로 날짜별 10시 누적 거래량 조회 확인 (과거 데이터는 며칠분만 제공되어 부족한 날은 제외)
